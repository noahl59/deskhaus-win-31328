## About DeskHaus

DeskHaus brings several everyday office tasks into one compact workspace. Use it to prepare rich-text documents, create tables with calculations, work with spreadsheet data, and edit images through a layer-based workflow.

The application is designed for web and desktop use, with HTML and JavaScript at its core. Its single-file format supports offline workflows and avoids the need for a server or a conventional installation, making it practical for quick document, table, and image tasks across compatible Windows environments.

## Features

- Rich-text editing for document creation and formatting
- Table creation with calculation support
- Import data from Excel and CSV files
- Export tables to Excel-compatible files

- Export images as PNG, JPG, WebP, ICO, or GIF
